# Simrithi S: portfolio

Plain HTML, CSS and JavaScript, no build step. Hosted on AWS Amplify Hosting.

**Creative feature: the rising flood.** Tap the raindrop in the corner. Rain falls, the water climbs the page, and a "high-water mark" card tells why I build flood-risk tools (Varshik). The water and rain layers ignore pointer events, so navigation always works. Press Esc or "Let it drain" to reset. Honours `prefers-reduced-motion`.

Run locally: open `index.html`, or `python -m http.server`.

Sections: About, Skills, Projects, Journey (experience and achievements), Contact.
