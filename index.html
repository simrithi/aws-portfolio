Projects

Flagship · AWS

Varshik: street-level flood-risk map

Finds roads likely to hold water before the rain arrives. A vision pipeline (SegFormer, Depth Anything V2, YOLOv8) on Amazon SageMaker scores 60 m road cells from dashcam frames, terrain and rainfall. Amazon Bedrock writes plain-language risk briefs. The React and MapLibre front end is served from S3 and CloudFront.

Top-risk cells matched Delhi's official flood hotspots (AUC 0.66, preliminary).

AWS SageMaker · Bedrock · S3 · CloudFront · CDK · YOLOv8 · React

Backend

FlashSale: oversell-proof inventory

An atomic stock-reservation engine using Redis Lua scripts, so check-and-decrement is one operation and two buyers can never claim the last unit. Adds a virtual waiting room, token-bucket rate limiting behind Nginx, and RabbitMQ workers that release unpaid stock.

Zero oversells under Locust load tests.

Node.js · Redis (Lua) · RabbitMQ · PostgreSQL · Nginx · Docker

Serverless · AWS

CareerLens: placement tracker

Event-driven backend on Lambda and API Gateway with a single-table DynamoDB design, behind separate student and company portals. An LLM turns unstructured placement notices into structured drives with eligibility matching. Hosted on Amplify, monitored with CloudWatch.

Lambda · API Gateway · DynamoDB · Amplify · React · Gemini
