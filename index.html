Projects

Four things I built, one spotlight each.

01

Varshik

A street-level flood-risk map

A vision pipeline on Amazon SageMaker (SegFormer, Depth Anything V2, YOLOv8) scores 60 m road cells for waterlogging risk from dashcam frames, terrain and rainfall. Amazon Bedrock writes the plain-language briefs. React and MapLibre, served from S3 and CloudFront.

Top-risk cells matched Delhi's official flood hotspots. Results are preliminary.

Live demoGitHubVideoBlog post

02

CareerLens

A serverless placement platform

Students get a re-plannable roadmap, honest ATS feedback and an applications tracker. Recruiters get blind, skill-first ranking. Built solo on Cognito, API Gateway, about 30 Lambda functions, DynamoDB, S3 and EventBridge, with an LLM that turns messy placement notices into structured drives.

Lambda, API Gateway, DynamoDB, Cognito, EventBridge, Amplify, React, Gemini

GitHub

03

FlashSale

Inventory that never oversells

One Redis Lua script makes check-and-decrement a single atomic step, so two buyers can never claim the last unit. A virtual waiting room, token-bucket rate limiting behind Nginx and RabbitMQ workers that release unpaid stock complete it.

Zero oversells under Locust load tests.

Node.js, Redis, RabbitMQ, PostgreSQL, Nginx, Docker
